# Learning System

## 原则
- 不以孤立背单词为主
- 用真实 README / 官方技术资料学习
- 听、说、读、写全部嵌入工作
- 每次学习必须有输出

## 每日 2 小时建议结构
### 40–45 分钟：English + Read
真实材料、发音、词义、表达、连读。

### 40–45 分钟：Research + Think
AI / 能源 / 产品逻辑拆解。

### 30 分钟左右：Output
英文复述、README、邮件、研究摘要或方案。

## 长期主题
1. Study Mode / Socratic Learning
2. Agent 架构
3. Codex / Claude Code / 其他智能体框架
4. AI 产品设计
5. 能源技术英语
6. 国际商务英语

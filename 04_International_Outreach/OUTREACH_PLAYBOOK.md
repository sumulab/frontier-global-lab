# International Outreach Playbook

## 第一原则
不为了练英语而发邮件。
只在我们能提出真实价值、真实问题或真实合作可能时联系。

## 外联前四问
1. 他是谁？
2. 他现在在解决什么问题？
3. 为什么这个问题和我们的能力 / 中国供应链有关？
4. 我们能为他提供什么？

四问答不出来，不发。

## 成功阶梯
1. 对方愿意 response
2. 愿意继续交流
3. 愿意提供真实问题 / 场景
4. 愿意让我们参与研究 / 方案
5. 咨询 / 居间 / 项目 / 合作 / 收入

## 频率
- 每天研究 1 个对象
- 初期每周发送 2–3 封高质量邮件
- 不为了完成数量 KPI 发送低质量邮件

## 复盘指标
- 是否回复
- 回复时间
- 回复质量
- 对方关注点
- 哪句话触发兴趣
- 哪个判断明显错误
- 下一轮如何优化

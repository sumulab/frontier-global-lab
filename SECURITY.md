# Security Policy

## Supported version

Security fixes target the latest tagged public release.

## Reporting

Do not open a public issue for suspected credentials, private workspace data,
or other sensitive information. Contact the repository owner privately through
the security-reporting channel configured on GitHub.

## Repository boundary

This public repository must not contain operational credentials or private
workspace data. If sensitive material is committed, rotate affected credentials
first, then remove the material from Git history and review all derived copies.
